# auriane-privacy

Hébergement public de la politique de confidentialité de l'app Auriane.

Source de vérité : le repo privé de l'app. Ce repo est le miroir public servi via GitHub Pages, et son URL est celle déclarée à Apple/Google.

## Mettre à jour

1. Éditer `index.md` (FR) ou `en.md` (EN).
2. Mettre à jour la date "Dernière mise à jour" / "Last updated" en haut.
3. Commit + push. GitHub Pages republie automatiquement (~30 s).
