# Support — Auriane

**Dernière mise à jour : 22 mai 2026**

Auriane est une application développée par un développeur indépendant. Si vous avez une question, un problème, ou une suggestion, vous êtes au bon endroit.

## Contact

Pour toute question, signalement de bug ou demande de fonctionnalité :

**`auriane-app@proton.me`**

Nous répondons sous quelques jours ouvrés.

## Questions fréquentes

### Mes données sont-elles envoyées sur un serveur ?

Non. Auriane n'a pas de serveurs. Vos données restent sur votre téléphone. Si vous activez la sauvegarde cloud, une copie est envoyée dans **votre propre** iCloud Drive (iPhone) ou Google Drive (Android) — votre compte, pas le nôtre. Voir la [politique de confidentialité](/) pour le détail.

### Comment activer la sauvegarde cloud ?

Dans l'application : **Réglages → Sauvegarde**. Choisissez iCloud (iOS) ou Google Drive (Android). La sauvegarde est optionnelle ; vous pouvez l'activer ou la désactiver à tout moment.

### J'ai changé de téléphone. Comment récupérer mes données ?

Si vous aviez activé la sauvegarde cloud avant : installez Auriane sur le nouvel appareil, connectez-vous au même compte iCloud / Google Drive, et utilisez **Réglages → Restaurer** dans l'application.

Si vous n'aviez pas activé la sauvegarde cloud, les données sont restées sur l'ancien téléphone. Sur iPhone, elles peuvent avoir été incluses dans la sauvegarde iCloud automatique de l'appareil (gérée par Apple).

### Comment supprimer mes données ?

- **Un événement, une photo, un enfant** : depuis l'application, sélection puis suppression.
- **Tout effacer** : désinstaller l'application supprime toutes les données locales. Si vous aviez activé la sauvegarde cloud, supprimez-la d'abord via **Réglages → Sauvegarde → Supprimer la sauvegarde**, ou directement depuis votre iCloud Drive / Google Drive.

### L'application ne se lance plus / je vois un écran d'erreur

Essayez d'abord de fermer complètement l'app et de la relancer. Si le problème persiste, écrivez-nous à `auriane-app@proton.me` en précisant votre modèle de téléphone et la version de l'OS — nous vous aiderons à récupérer vos données avant toute action plus radicale.

### Je voudrais une nouvelle fonctionnalité

Écrivez-nous, on lit tout. Auriane est un projet personnel développé sur le temps libre, on ne peut pas tout faire mais on s'inspire des retours pour les prochaines versions.

### L'application est-elle disponible dans d'autres langues ?

V1 : français et anglais. D'autres langues pourront être ajoutées selon les retours.
